Fibonacci

Aim: To study and implement the Fibonacci sequence using recursive and iterative methods.
C++ 
#include <iostream>
using namespace std;

int fibonacci(int n)
{
    if(n <= 1)
        return n;

    return fibonacci(n - 1) + fibonacci(n - 2);
}

int main()
{
    int n;

    cout << "Enter number: ";
    cin >> n;

    cout << "Fibonacci = " << fibonacci(n);

    return 0;
}
C++ 
#include <iostream>
using namespace std;

int main()
{
    int n;

    cout << "Enter number: ";
    cin >> n;

    int a = 0;
    int b = 1;

    if(n == 0)
    {
        cout << a;
    }
    else if(n == 1)
    {
        cout << b;
    }
    else
    {
        for(int i = 2; i <= n; i++)
        {
            int c = a + b;

            a = b;
            b = c;
        }

        cout << b;
    }

    return 0;
}

Algorithm: Fibonacci

  1. Start.
  2. Input the value of n.
  3. If n is 0 or 1, return n.
  4. For the recursive method, calculate Fibonacci(n-1) + Fibonacci(n-2).
  5. For the iterative method, initialize the first two values as 0 and 1.
  6. Repeatedly calculate the next value by adding the previous two values.
  7. Display the Fibonacci value.
  8. Stop.

Binary Search Tree

Aim: To study the Binary Search Tree (BST) structure and implement search operation using the BST property.
C++ 
#include <iostream>
using namespace std;

struct TreeNode
{
    int val;
    TreeNode *left;
    TreeNode *right;

    TreeNode(int x)
    {
        val = x;
        left = NULL;
        right = NULL;
    }
};

TreeNode* searchBST(TreeNode* root, int val)
{
    if(root == NULL)
    {
        return NULL;
    }

    if(root->val == val)
    {
        return root;
    }
    else if(val < root->val)
    {
        return searchBST(root->left, val);
    }
    else
    {
        return searchBST(root->right, val);
    }
}

int main()
{
    TreeNode *root = new TreeNode(4);

    root->left = new TreeNode(2);
    root->right = new TreeNode(7);

    root->left->left = new TreeNode(1);
    root->left->right = new TreeNode(3);

    int val;

    cout << "Enter value to search: ";
    cin >> val;

    TreeNode *result = searchBST(root, val);

    if(result != NULL)
    {
        cout << "Node found: " << result->val << endl;
    }
    else
    {
        cout << "NULL" << endl;
    }

    return 0;
}

Algorithm: Search in Binary Search Tree

  1. Start.
  2. Set the root node as the current node.
  3. If the current node is NULL, the value is not found.
  4. If the value is equal to the current node value, the node is found.
  5. If the value is smaller than the current node value, move to the left child.
  6. Otherwise, move to the right child.
  7. Repeat the process until the value is found or the current node becomes NULL.
  8. Stop.

AVL / Balanced BST

Aim 1: To convert an unbalanced Binary Search Tree (BST) into a height-balanced Binary Search Tree while preserving all node values.

Aim 2: To balance a Binary Search Tree using inorder traversal and reconstruction.
C++ 
class Solution
{
public:

    vector<int> arr;

    void inorder(TreeNode* root)
    {
        if(root == NULL)
            return;

        inorder(root->left);

        arr.push_back(root->val);

        inorder(root->right);
    }

    TreeNode* build(int low, int high)
    {
        if(low > high)
            return NULL;

        int mid = (low + high) / 2;

        TreeNode* root = new TreeNode(arr[mid]);

        root->left = build(low, mid - 1);

        root->right = build(mid + 1, high);

        return root;
    }

    TreeNode* balanceBST(TreeNode* root)
    {
        inorder(root);

        return build(0, arr.size() - 1);
    }
};

Algorithm: Convert Unbalanced BST to Height-Balanced BST

  1. Start.
  2. Perform inorder traversal of the given BST.
  3. Store all node values in an array.
  4. The inorder traversal produces the values in sorted order.
  5. Find the middle element of the array.
  6. Create a new node using the middle element as the root.
  7. Recursively build the left subtree using the left half of the array.
  8. Recursively build the right subtree using the right half of the array.
  9. Return the newly balanced BST.
  10. Stop.
